# FirstApp

A first Angular single-page app: routed pages with a shared navbar and footer, built to practice Angular components and routing.

## Features

- Home, About and Contact pages
- Gallery section with nested routes (Headphones, Airbuds)
- Custom 404 page
- Shared navbar and footer components
- Page titles per route

## Tech Stack

- Angular 20 (standalone components, signals)
- TypeScript
- Bootstrap 5
- Font Awesome
- Jasmine and Karma for tests

## Run Locally

```bash
git clone https://github.com/Yosef-Tamer206/FirstApp.git
cd FirstApp
npm install
ng serve
```

Then open http://localhost:4200/.

## Other Commands

```bash
ng build   # production build into dist/
ng test    # run unit tests
```
